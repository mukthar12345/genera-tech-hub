# 🔧 Genera Tech Hub

**Technology You Can Trust** — A modern technology hub for phone & laptop sales, repairs, and trade-ins.

---

## 🎯 About

Genera Tech Hub is a full-service technology business offering:

- 📱 Phone & laptop sales
- 🔧 Repair services
- 🔄 Trade-in & swap program
- 🎧 Accessories
- 💻 Software installation & upgrades

---

## 🛠️ Technology Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Database:** Supabase (PostgreSQL)
- **Auth:** Supabase Auth
- **Storage:** Supabase Storage
- **Charts:** Chart.js
- **Hosting:** Netlify (recommended)
- **Version Control:** GitHub
